# Systematic Long-Short Equity Research

## Build

From the repository root, compile using the saved figures:

```bash
cd report
latexmk -pdf -jobname=report -interaction=nonstopmode -halt-on-error main.tex
```

If `latexmk` is absent from `PATH`, use `/Library/TeX/texbin/latexmk`.
The multi-file document requires a complete TeX distribution with BibTeX.
Compilation requires no Python or analytical run. Regenerate the two report
diagrams only when changing their generator:

```bash
/opt/anaconda3/bin/conda run -n finance python report/scripts/generate_assets.py
```

Run this command from the repository root before compiling. It uses Matplotlib
and the TeX distribution's Latin Modern fonts, located with `kpsewhich`.

## Structure

- `main.tex`, `preamble.tex`, `sections/`, `references.bib`: document sources.
- `scripts/generate_assets.py`: generator for the two report-specific diagrams.
- `figures/`: generated 300 dpi PNGs for the architecture and evaluation timeline.
- `evidence/competition_context.md`: competition rules, questionnaire and
  calibration formulas.
- `evidence/momentum_selection/`: the five-candidate historical comparison,
  monthly returns, metrics and status files; its
  [README](evidence/momentum_selection/README.md) explains the periods, fields
  and file hashes.
- `report.pdf`: compiled report.
- `.gitignore`: excludes temporary LaTeX files and Python caches.
